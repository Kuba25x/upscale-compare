# README screenshot provenance

The README images are captures of the actual frontend-only demo, without UI
mockups, compositing or invented application screens. Both use synthetic PNG
patterns generated by the existing tests/e2e/fixtures.ts helper and label them
Synthetic A / Synthetic B. No game footage, personal data, trademarks belonging
to games or externally sourced photographs are included.

- docs/images/desktop-split.jpg: web demo, Split Screen, 1280 × 900 CSS pixels, DPR 1.
- docs/images/mobile-side-by-side.jpg: mobile web demo, Side-by-Side,
  412 × 915 CSS pixels, DPR 1.

The mobile capture is browser emulation; it is not evidence of native Android
system bars, a Photo Picker or physical-device qualification. JPEG screenshot
compression affects this documentation asset only. Original imported files
inside the application are not modified.

To reproduce on a trusted development checkout:

```sh
npm ci
npx playwright install --with-deps chromium
node scripts/capture-readme.mjs
```

The script builds the demo, starts a local preview, imports the repository's
generated images and waits for image decode, fonts and rendering before
capturing. Files are written to release-artifacts/screenshots/. Copy reviewed
captures into docs/images/. The optional --emit-base64 flag exposes only those
public synthetic screenshots for transfer from a CI runner; it never captures
user files.

The original committed captures are associated with the preparation PR and its
Actions run. They retain the application's existing visual style.
